FORMAT / CONFIGURATION
v2 media and instance ABI are incompatible with v1/Zephyr NVS.
Export old values before explicit migration; no in-place format upgrade is claimed.
One private build choice: full / boot / readonly. Public header has no configuration macros.
All builds use CRC32 and the same ABI/media; geometry lives only in znvs_cfg_t.
